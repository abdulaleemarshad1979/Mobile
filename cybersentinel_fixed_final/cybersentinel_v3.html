Incident Analysis

HOW THE ATTACK UNFOLDED

A step-by-step breakdown of how a single unscanned evidence device brought down a government cybercell's forensic infrastructure.

01
Evidence Device Seized
Confiscated OnePlus device with compromised firmware — attacker pre-infected device before planting it as evidence.
02
Direct Connection Made
Investigator plugged device directly into forensic workstation via USB without pre-screening. Standard ADB session opened.
03
Auto-Execution (8s)
BadUSB HID payload spoofed keyboard, injected PowerShell commands, downloaded second-stage ransomware dropper.
04
Lateral Movement
SMB/EternalBlue variant propagated to 2 adjacent forensic workstations on the same LAN within 4 minutes.
05
Data Encrypted (4h)
Ransomware.Shadow.B activated after dormancy period, encrypting all forensic case data and system files.
06
CyberSentinel Prevention
CyberSentinel would have flagged the BadUSB HID descriptor and TheTruthSpy firmware signature before any connection was made.

Connect Evidence Device

Connect a real Android device via USB · Enable USB Debugging in Developer Options

Device not detected? Enable USB Debugging on your phone:
1
Enable Developer Options
Go to Settings → About Phone (or Software Info) and tap "Build Number" 7 times until you see "You are now a developer!"
iQOO/Vivo: Settings → About Phone → Software Information → Build Number
2
Turn on USB Debugging
Go to Settings → System → Developer Options and toggle "USB Debugging" ON.
iQOO/Vivo: Settings → System & Updates → Developer Options → USB Debugging
3
Set USB Mode to File Transfer
After plugging in, swipe down the notification bar on your phone. Tap the USB notification and select "File Transfer (MTP)" instead of "Charging only".
4
Authorize this Computer
A popup will appear on your phone: "Allow USB debugging?" — tap Allow (check "Always allow from this computer").
If no popup appears, unplug and replug the cable, or revoke USB debugging authorizations in Developer Options and try again.
5
Use a Data Cable
Some USB cables are charge-only. Make sure your cable supports data transfer. Try a different cable or port if the device still doesn't appear.
Windows users: Use start.bat instead of bash start.sh for proper USB device access. WSL (Linux subsystem) cannot access Windows USB devices.

Technical Overview

HOW IT WORKS

Six scanning phases run in strict isolation — no malware can reach the forensic workstation.

01
USB Descriptor Analysis
Device USB class descriptors enumerated at hardware level. Dual HID + Mass Storage (BadUSB pattern) flagged before any data flows.
02
Firmware Integrity Check
ro.build.fingerprint and build signatures validated. Test-keys, dev-keys, userdebug builds, and injected su binaries detected.
03
Network Beacon Detection
Active TCP/UDP sockets inspected against 34 known C2 IPs and 24 suspicious ports. Real-time C2 communication detected live.
04
IOC Package Scan
137 malware package signatures matched: stalkerware, RATs, banking trojans, ransomware, and Pegasus IOCs from CERT-IN, CAS, CitizenLab.
05
Heuristic Scoring Engine
Unknown apps scored by permission combos, MITRE ATT&CK patterns, namespace masquerades, and behavioral indicators — no signature required.
06
AI Forensic Analysis
Groq LLaMA-3.3-70B synthesizes all scan data into a forensic verdict with immediate isolation actions and chain-of-custody recommendations.

FastAPI v0.110+ Backend
Async Python with Pydantic v2, WebSocket streaming, lifespan hooks, structured JSON logging. CORS-protected, rate-limited.
Android Debug Bridge (ADB)
Async subprocess wrapper with per-command timeouts. Falls back to realistic demo mode when ADB is unavailable.
Threat Intelligence DB v3
137 malware packages, 34 C2 IPs, 10 permission combos, 8 heuristic rules. Sources: CERT-IN, CAS, CitizenLab, Threatfabric, Europol.
VirusTotal Integration
Optional APK hash lookup. Only triggered on already-flagged packages to conserve API quota. Configurable via VIRUSTOTAL_API_KEY in .env.

LLaMA-3.3-70B with 3-attempt retry + exponential backoff, Pydantic-validated response, context-aware forensic chat (20-message history cap).
